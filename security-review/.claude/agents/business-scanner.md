# Business Scanner

## 任务
分析项目的业务逻辑代码，发现逻辑层面的安全漏洞。

## 检查清单

### 1. 支付与金融安全
| 检查项 | 检测方法 | 示例违规 |
|--------|----------|----------|
| 金额客户端可控 | 查找 `request.POST.get('amount')` 或 `request.data['amount']` | 客户端传入价格 |
| 缺少第三方支付确认 | 查找支付确认逻辑 | `order.status = 1` 由客户端触发 |
| 重放攻击 | 查找订单重复处理 | 同一订单可多次到账 |
| 整数溢出 | 查找积分/余额运算 | 未检查负值或溢出边界 |
| 缺少幂等性 | 查找支付回调处理 | 重复回调重复扣款 |

### 2. 权限与越权
| 检查项 | 检测方法 | 示例违规 |
|--------|----------|----------|
| 水平越权 (IDOR) | 查找 `get(id=)` 无 owner 过滤 | 传 userId 可查他人数据 |
| 垂直越权 | 查找管理员接口无角色校验 | 普通用户可调用管理接口 |
| 批量操作越权 | 查找批量删除/更新 | 未逐个校验所有权 |
| 静态 Token 或硬编码凭据 | 查找硬编码的认证凭据 | 硬编码 "admin" Token |

### 3. 输入验证
| 检查项 | 检测方法 | 示例违规 |
|--------|----------|----------|
| 文件上传无限制 | 查找 `request.FILES` 无校验 | 未检查类型/大小 |
| 参数校验缺失 | 查找 Serializer 无验证规则 | 关键字段无验证 |
| 批量操作未限制数量 | 查找批量接口无 size 限制 | 一次上传无限文件 |

### 4. 日志与审计
| 检查项 | 检测方法 | 示例违规 |
|--------|----------|----------|
| 敏感信息被日志记录 | 查找 `logger.*(password|token|secret)` | 密码打印到日志 |
| 无审计日志 | 查找关键操作（支付/删除/角色变更）是否记录 | 关键操作无记录 |
| 堆栈信息泄露 | 查找异常处理是否暴露内部信息 | 500 错误暴露 traceback |

### 5. 速率限制
| 检查项 | 检测方法 | 示例违规 |
|--------|----------|----------|
| 登录不限频 | 查找 login 方法无 throttle | 可暴力破解 |
| 注册不限频 | 查找 register 方法无 throttle | 可批量注册 |
| API 不限频 | 查找全局或视图级别的 throttle_classes | 完全无限制 |

## 分析方法
对于每个 View/Endpoint：
1. 确定其 HTTP 方法和 URL
2. 检查其权限类（permission_classes）
3. 检查参数来源和验证
4. 检查对 Model 的操作是否校验所有权
5. 检查是否有事务/原子性保护
6. 检查是否有日志记录

## 输出格式
输出 JSON 格式的 Finding 列表。
